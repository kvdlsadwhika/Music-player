# Music-player

Melody Music Player

About the Project

Melody Music Player is a simple and responsive music player website created using HTML, CSS, and JavaScript.

The website has a clean and attractive dark theme with a modern music-player design. Users can select songs, play or pause music, move between songs, adjust the volume, and search for songs.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- Responsive music player design
- Play and pause songs
- Previous and next song buttons
- Song progress bar
- Volume control
- Song playlist
- Search songs and artists
- Album cover display
- Recommended music section
- Responsive design for mobile and desktop

Project Structure

Music-Player/

HTML

HTML is used to create the basic structure of the website.

It contains:

- Sidebar navigation
- Search bar
- Music player
- Album image
- Song information
- Playlist
- Recommended songs
- Audio element

CSS

CSS is used to design and style the music player.

It is used for:

- Colors and backgrounds
- Flexbox and Grid layouts
- Buttons
- Cards
- Album images
- Hover effects
- Spacing and alignment
- Responsive design

JavaScript

JavaScript is used to make the music player interactive.

It handles:

- Play and pause
- Next and previous songs
- Song selection
- Progress bar
- Volume control
- Song search
- Updating song title and artist
- Changing album images

How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Use the music player to play and control the songs.

Responsive Design

The website is designed to work on different screen sizes.

It supports:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adjust the layout for smaller screens.
